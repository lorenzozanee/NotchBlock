# NotchBlock v0.2.0 产品规划

> 2026-06-04 | 双代理并行调研 + 红蓝对抗分析

## 调研结论

### WeChat 集成可行性

经过 8 种方案对比，**WxPusher** 是唯一可行的路径：

| 方案 | 可行性 | 风险 |
|---|---|---|
| WxPusher (第三方推送) | 9/10 ✅ | 低 — 免费, REST API, 无需服务器 |
| 企业微信 Webhook | 7/10 | 中 — 消息仅到企业微信 app |
| 公众号/小程序/开放平台 | 1-3/10 ❌ | 需要中国营业执照 |
| 非官方 API | 6/10 ❌ | 极高 — 96.5% 检出率封号风险 |

### Apple 生态扩展

**关键发现:** CloudKit / iPhone / Watch 全部要求 Apple Developer Program ($99/年)。

| 功能 | 可行性 | 开发者账号? | 建议版本 |
|---|---|---|---|
| macOS WidgetKit | 9/10 | 否 | v0.3.0 |
| SwiftData 迁移 | 8/10 | 否 | v0.3.0 |
| iPhone 伴侣 | 6/10 | 是 | v0.3.0 |
| Apple Watch | 4/10 | 是 | v0.4.0 |

## 验收标准

### AC 5.0: 微信通知
- 设置中配置 appToken + UID
- 任务结束时自动发送微信通知
- appToken 使用 Keychain 安全存储
- 企业微信 Webhook 备选渠道

### AC 6.0: 自动过期标记修复
- BlockScheduler 持续运行, 不依赖主窗口
- 启动/休眠恢复时立即检查过期任务

### AC 7.0: 每日统计摘要
- 今日完成率 + 专注时间
- 本周完成趋势

### AC 8.0: UI 刷新
- NSVisualEffectView 加深毛玻璃
- Spring 动画 (面板/遮罩)
- 统一圆角间距规范
