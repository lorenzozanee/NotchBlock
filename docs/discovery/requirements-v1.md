# NotchBlock v0.5.1 — Requirements Document v1

**生成日期**: 2026-06-05 | **模式**: 加速（跳过追问）
**复杂度**: Small（≤1月）

---

## 项目概述

NotchBlock 是 macOS 时间块强制执行工具，将 Mac 硬件刘海转化为隐形交互入口。当前 v0.6.0 已实现核心功能（刘海悬停、全屏遮罩强提醒、排程面板），v0.5.1 聚焦 UI/UX 打磨和用户引导。

---

## 用户故事

### Feature 3: 自定义图标 + UI 美化
- **P0**: 作为用户，我希望看到有辨识度的菜单栏图标，而不是系统 SF Symbol，让我一眼认出 NotchBlock
- **P0**: 作为用户，我希望排程面板看起来精致专业，有现代 macOS 应用的质感
- **P1**: 作为用户，我希望刘海面板（NotchPanel）和遮罩界面（Overlay）也有统一的视觉风格

### Feature 4: 首次启动配置向导
- **P0**: 作为新用户，我第一次打开应用时希望看到一个简洁的引导流程，告诉我这个应用怎么用
- **P0**: 作为新用户，我希望在引导中设置每天的专注时段、休息偏好
- **P1**: 作为新用户，我希望引导完成后看到排程面板已经有示例任务，方便理解用法

### Feature 5: 排程面板优化
- **P0**: 作为用户，我希望排程面板用时间轴可视化展示任务，比纯列表更直观
- **P1**: 作为用户，我希望任务行有状态颜色标识（进行中=绿色、已超时=红色、已完成=灰色）
- **P1**: 作为用户，我希望空状态引导更友好，有快捷入口
- **P2**: 作为用户，我希望可以通过拖拽调整任务时间

## 功能需求

### FR-3: 图标与 UI

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-3.1 | 设计/替换 App 图标（AppIcon），使用时间+专注主题的视觉元素 | P0 |
| FR-3.2 | 菜单栏图标支持自定义：提供 3-5 个预设图标选项，用户可在设置中切换 | P0 |
| FR-3.3 | 排程面板视觉升级：圆角卡片化、渐变背景、更精致的阴影和间距 | P0 |
| FR-3.4 | NotchPanel 视觉优化：更流畅的动画曲线、毛玻璃效果增强 | P1 |
| FR-3.5 | 统一配色方案：定义 App 级别的 accent color 和 semantic colors | P0 |
| FR-3.6 | 遮罩界面（Overlay）视觉改进：更柔和的颜色、可读性更好的倒计时 | P1 |

### FR-4: 首次启动配置

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-4.1 | 首次启动显示配置向导窗口（3 步：欢迎 → 偏好设置 → 完成） | P0 |
| FR-4.2 | 第 1 步 - 欢迎页：功能介绍（刘海悬停、时间块排程、全屏专注提醒） | P0 |
| FR-4.3 | 第 2 步 - 偏好设置：设置每日专注时段（默认 09:00-18:00）、是否开启开机自启 | P0 |
| FR-4.4 | 第 3 步 - 完成页：展示今日示例任务，提示菜单栏图标位置，引导完成 | P0 |
| FR-4.5 | 配置数据持久化到 UserDefaults，后续可在设置中修改 | P0 |
| FR-4.6 | 替换现有的简单欢迎通知（`sendWelcomeNotification`） | P1 |

### FR-5: 排程面板

| ID | 需求 | 优先级 |
|----|------|--------|
| FR-5.1 | 时间轴视图：左侧显示时间刻度（06:00-24:00），右侧任务块按时间比例排列 | P0 |
| FR-5.2 | 状态颜色编码：pending=品牌蓝、active=绿色脉冲、completed=灰色、missed=红色 | P0 |
| FR-5.3 | 空状态优化：首次使用显示「添加你的第一个任务」引导卡片 | P1 |
| FR-5.4 | 快速操作：任务行悬停显示快速完成/编辑按钮（无需右键菜单） | P1 |
| FR-5.5 | 任务列表和迷你日历/时间轴可切换视图 | P2 |

## 非功能需求

- **性能**: UI 动画保持 60fps，时间轴视图滚动流畅
- **兼容性**: macOS 14.0+，适配 Light/Dark 模式
- **可访问性**: 颜色编码同时使用图标区分状态（不依赖颜色）
- **本地化**: 中文界面（当前用户群体）

---

## 约束与假设

- **约束**: SwiftUI + AppKit 混合架构保持不变
- **约束**: 不引入第三方 UI 框架（仅用系统组件）
- **假设**: 用户群体为中文用户，界面保持中文
- **假设**: 图标设计使用 AI 生成 + 手动调整，不聘请设计师
